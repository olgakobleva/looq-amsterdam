## 2. АНАЛИЗ МИРОВОГО РЫНКА ВИНОДЕЛЕН

### 2.1 Глобальные тренды рынка 2025–2026

**Рынок вина B2B** переживает цифровую трансформацию:
- Онлайн-продажи вина выросли на 43% за 2022–2025
- 65% трафика виноделен приходит с мобильных устройств
- B2B e-commerce для алкоголя — самый быстрорастущий сегмент
- Прямые продажи (DTC — Direct to Consumer) выросли на 68% в США за 3 года
- Оптовые продажи через цифровые порталы растут на 25% ежегодно

### 2.2 Что хотят рестораны от сайта винодельни
1. **Технические листы (Tech Sheets)** — немедленная загрузка в PDF
2. **Аллокации и наличие** — real-time информация о запасах
3. **Vintage reports** — отчёты по каждому урожаю
4. **Food pairing** — сочетания с блюдами для меню сомелье
5. **Оптовые прайсы** (защищённая зона, только для авторизованных)
6. **Минимальные партии** и условия доставки
7. **Тренинговые материалы** — обучение персонала ресторана

### 2.3 Что хотят ритейлеры
1. **Высококачественные фотографии** (bottle shots, lifestyle) для своего маркетинга
2. **Точки продаж (POS materials)** — shelf talkers, витринные материалы
3. **Описания вин** готовые к копированию для своих каталогов
4. **История бренда** адаптированная для продавцов
5. **Наличие и аллокации** по регионам
6. **B2B портал** с персональными условиями

### 3.1 Платформы для виноделен
| Платформа | Назначение | Подходит для La Bandita |

- **AR (WebAR)** — этикетки оживают через камеру смартфона
- **QR-коды** на этикетках → цифровые tasting notes
- **NFC теги** — luxury packaging с мгновенным доступом к информации
- **Drone video** — аэросъёмка виноградника
- **360° VR тур** по погребу и виноградникам (Three.js panorama)

## 4. ФОРУМЫ И ИДЕИ, КОТОРЫЕ ЕЩЁ НЕ РЕАЛИЗОВАНЫ

### 4.1 Обсуждаемые, но нереализованные идеи (источники: WineBerserkers, Wine Industry Advisor, Medium/Paul Mabray)

**Идеи которые обсуждают но редко делают:**

1. **"Wine Passport" для оптовых клиентов** — персональный профиль сомелье/закупщика с историей заказов, дегустационными заметками и кастомными рекомендациями

2. **Live Allocation Tracker** — real-time отображение сколько бутылок осталось от урожая конкретного года (создаёт FOMO у покупателей)

3. **Sommelier Training Hub** — скрытый раздел сайта только для партнёров с обучающими видео, flashcards, тестами по вину

4. **Интерактивная карта дистрибуции** — "найдите наше вино в вашем городе/стране"

5. **Vintage Comparison Tool** — сравнить два урожая по органолептике, климату, оценкам критиков

6. **"Reserve Your Barrel" Experience** — luxury опция купить фьючерс на бочку (en primeur для Тосканы)

7. **AI-ассистент сомелье** — чат-бот отвечает на вопросы о вине, паринге, vintage

8. **Vineyard Cam** — прямая трансляция с виноградника по сезонам (особенно в harvest time)

9. **Carbon Footprint Calculator** — для ESG-ориентированных ритейлеров, показывает экологичность

10. **White Label Assets Portal** — ритейлеры скачивают готовые POS-материалы, адаптированные под их брендинг

### 4.2 Что уже делают топ-игроки (но La Bandita пока нет)
- Интеграция с Vivino, Wine-Searcher, Wine Spectator — автоматическое обновление рейтингов
- Прямая интеграция с POS-системами ресторанов (Toast, Square)
- Email-капельные воронки для оптовых клиентов (образование → доверие → заказ)
- Subscription wine club (ежеквартальные аллокации для частных клиентов)

## 5. ИЗОБРАЖЕНИЯ И ВИЗУАЛЬНЫЙ КОНТЕНТ

### 5.1 Необходимые имиджи для сайта

#### Hero / Главная страница
- **Drone shot** виноградника La Bandita в золотой час (sunset)
- **Slow-motion video loop** — вино льётся в бокал
- **Cinematic still** — бутылки на каменном фоне / деревянном столе

#### Продуктовые фото
- **Pack shots** — профессиональные фото бутылок на белом / нейтральном фоне
- **3D asset** бутылки для интерактивного вьювера (GLB/GLTF формат)
- **Lifestyle shots** — бутылки в контексте: ресторан, открытая терраса, погреб
- **Detail shots** — крупный план этикетки, пробки, горлышка

#### Виноградник и производство
- Аэросъёмка виноградника по сезонам (весна/лето/осень/зима)
- Портреты виноделов / команды (аутентичные, не постановочные)
- Процесс производства: сбор урожая, прессование, бочки, дегустация
- Подвал / cantina — архитектурные снимки

#### B2B / Trade секция
- Ресторанные сеттинги с вином на столе
- Sommelier в действии
- Переговоры, дегустации, презентации

### 5.2 Стиль фотографии
- **Тёплая тосканская палитра** — золотые, терракотовые, охристые оттенки
- **Текстуры** — камень, дерево, глина, лён
- **Естественный свет** — минимальная студийная обработка
- **Кинематографичность** — широкий формат, глубина резкости

## 6. ВИЗУАЛЬНАЯ ИДЕНТИФИКАЦИЯ

### 6.1 Цветовая палитра (на основе этикеток La Bandita)
По имеющимся данным этикетки используют:
- **Глубокий бордо / Burgundy** `#5C1A1A` — основной цвет красного вина
- **Золото / Antique Gold** `#C9A84C` — акцентный, для премиум деталей
- **Кремовый / Parchment** `#F5EED8` — фон этикетки
- **Тёмный уголь / Charcoal** `#1C1C1E` — текст, навигация
- **Тосканская терракота** `#A0522D` — вторичный акцент

### 6.2 Типографика (современная без засечек)
Рекомендации для современного сайта:
- **Заголовки**: `Neue Haas Grotesk` или `Aktiv Grotesk` (современный, элегантный)
- **Альтернативы**: `Inter`, `DM Sans`, `Plus Jakarta Sans` (бесплатно Google Fonts)
- **Акцент / логотип**: `Cormorant Garamond` (serif только для логотипа/акцентов — mix of modern+heritage)
- **Body text**: `Inter` 16px, line-height 1.7

## 9. РЕЗЮМЕ И РЕКОМЕНДАЦИИ

### Приоритеты реализации
1. **Немедленно**: Редизайн главной страницы + мобильная версия
2. **Краткосрочно (1–3 мес)**: B2B Trade Portal + 360° bottle viewer
3. **Среднесрочно (3–6 мес)**: Multilingual + Sommelier Hub + AR этикетка
4. **Долгосрочно**: Vineyard Cam + AI Wine Assistant + Subscription Club

### Конкурентное преимущество La Bandita
- **История с 1820** — редкое наследие в Болгери/Суверето
- **Тосканская аутентичность** — premium positioning
- **Boutique production** — эксклюзивность, FOMO для закупщиков
- **Family estate** — human story, ценится у millennial сомелье
